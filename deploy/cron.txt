# Host-side crontab for the Hound droplet (gerrit user)
# Install with: crontab -e  and paste the lines below
# Verify with:  crontab -l
#
# These entries are NOT auto-installed. They must be copied into the host
# crontab manually after any droplet rebuild. See
# docs/operations/digitalocean_droplet.md under "Scheduled host jobs".

# Rebuild the Beads top-tasks summary 5 minutes before the daily digest task
# fires at 10:00 UTC. Writes /opt/hound/state/beads_summary.json — the /state/
# directory is bind-mounted read-only into the worker container at
# /config/state/. (Directory mount, not single-file: see CLAUDE.md gotcha #62.)
# NOTE: this host cron is a fallback. The primary refresh path is the
# `.github/workflows/beads-summary.yml` workflow in the megarepo, which fires
# on every push to main touching .beads/** and rsyncs to the same path.
55 9 * * * cd /opt/hound && ./scripts/update_beads_summary.sh >> /home/gerrit/logs/beads_summary.log 2>&1
